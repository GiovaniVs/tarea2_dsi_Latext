	\subsection{1- Selenium}
	Selenium es un framework de pruebas automatizadas de aplicaciones web que permite interactuar con navegadores de manera programática para validar la funcionalidad de sitios web.\cite{qalified_selenium_testing}\\
	
		URL sito oficial: 
	\href{https://www.selenium.dev/}{Selenium}
	

	\begin{figure}[h!]

		\label{fig:selenium} 
	\end{figure}
	
	\subsubsection{Características}
	\begin{enumerate}
		\item Compatible con navegadores como Chrome, FireFox, Edge y Safari.
		\item Soporta múltiples lenguajes: Java, Python, C\#, Ruby, JavaScript.
		\item Permite integración con frameworks de testing (JUnit, TestNG, Pytest).
		\item Facilita pruebas de interacción con formularios, enlaces, botones y navegación en sitios web.
	\end{enumerate}

	\subsection{4- Cypress}
	Es un marco de pruebas y un conjunto de herramientas de código abierto para aplicaciones web que posibilita a los programadores redactar, implementar y depurar pruebas de manera confiable, fácil y rápida. Se enfoca en pruebas de frontend, pero también tiene la capacidad de llevar a cabo pruebas unitarias, de integración y de extremo a extremo (e2e). A diferencia de Selenium, Cypress tiene la capacidad de funcionar directamente en el navegador, brinda un test runner interactivo con la funcionalidad "time travel" para examinar el estado de la aplicación y ofrece acceso directo al DOM, las APIs del navegador y la red, así como depuración integrada. \cite{keepcoding_cypress_testing}\\
		URL sito oficial: 
	\href{https://www.cypress.io/}{Cypress}

	\subsection{LaTeX}
	LaTeX es un \textbf{sistema de preparación de documentos} orientado a la creación de textos con alta calidad tipográfica, especialmente útil para documentación técnica y científica.

	 %uimagen 
	 	\begin{figure}[h!]
	 	\centering
	 	\includegraphics[width=0.3\textwidth]{latex.png}
	 	\caption{Logo LaTex}  \cite{latex_logo}
	 	\label{fig:LaTex} 
	 \end{figure}
	
	\subsubsection {\textbf{Objetivo Principal}}
	Permitir a los autores concentrarse en el contenido, mientras \LaTeX{} se ocupa del formato y el diseño visual.
	
	\subsubsection{\textbf{Características Técnicas}}
	\begin{enumerate}
		\item \textbf{Lenguaje de marcado estructurado:}
		Define la estructura del documento (capítulos, secciones, figuras, tablas, etc.), separando contenido de formato.
		\item \textbf{Soporte avanzado de contenido técnico:}
		Excelente manejo de fórmulas matemáticas, bibliografías, índices, referencias cruzadas y soporte multilenguaje.
		\item \textbf{Extensible mediante paquetes:}
		Add-ons para gráficos, presentaciones, tablas complejas, etc. disponibles desde repositorios como CTAN.
		\item \textbf{Salida de alta calidad:}
		Producción de documentos PDF o formatos intermedios (DVI, PS), con posibilidad de conversión a HTML, XML, EPUB, etc., usando herramientas como \textit{Pandoc}, \textit{LaTeXML}, \textit{LaTeX2HTML}.
	\end{enumerate}
	
	\subsubsection{Ventajas}
	\begin{enumerate}
		\item \textbf{Calidad tipográfica:} ideal para publicaciones científicas, tesis y documentación técnica.
		\item \textbf{Separación entre contenido y formato:} permite reusar plantillas.
		\item \textbf{Extensible y adaptable:} Dispone de un amplio ecosistema de paquetes y herramientas disponibles.
		\item \textbf{Automatización avanzada:} Ideal para generar informes automatizados, como en entornos de análisis de datos.
	\end{enumerate}
	
	\subsubsection{\textbf{Desventajas}}
	\begin{enumerate}
		\item La curva de aprendizaje es más compleja en comparación con editores tradicionales.
		\item Requiere el aprendizaje de sintaxis.
	\end{enumerate}

	\subsection {AsciiDoc}
	Asciidoctor es una implementación rápida y eficiente del lenguaje de marcado AsciiDoc. Permite crear documentación técnica en archivos de texto plano y transformarlos en múltiples formatos de salida, tales como HTML, PDF, ePub y DocBook. Su enfoque está en ofrecer una sintaxis legible para humanos, manteniendo un alto nivel de estructuración en los documentos.\cite{asciidoctor}

	URL sito oficial: 
	\href{https://asciidoctor.org/}{AsciiDoc}

			\item Compatible con múltiples formatos de salida: HTML5, PDF, ePub, DocBook.
			\item Sintaxis clara y legible para documentación técnica.
			\item Soporte para tablas, notas, referencias, imágenes y bloques de código.
			\item Extensible mediante plantillas y estilos personalizados.
			\item Integración sencilla con sistemas de control de versiones (Git).
		\end{itemize}
		
	\begin{itemize}
		\item Multiplataforma (Windows, Linux, macOS).
		\item Funciona como herramienta de línea de comandos y como librería en proyectos Ruby, Java, JavaScript.

\subsection{Sphinx}
	Sphinx es una herramienta para la creación de documentación que se originó en el entorno de Python. Permite la entrada de archivos en Markdown o reStructuredText (reST) y es capaz de crear documentación en diferentes formatos, como ePub, PDF  LaTeX, HTML, entre otros. Está particularmente enfocado en la documentación técnica y los manuales de usuario, proporcionando resultados estructurados y profesionales.\cite{sphinx_doc}\\
	URL sito oficial: 
	\href{https://www.sphinx-doc.org/en/master}{Sphinx}
	%imagen 
	\begin{figure}[h!]
		\centering
		\includegraphics[width=0.3\textwidth]{sphinx_logo.png}
		\caption{Logo Sphinx}\cite{sphinx_doc}
		\label{fig:Sphinx} 
	\end{figure}

	\subsubsection{Características}
		\begin{itemize}
		\item Entrada basada en reStructuredText o Markdown, permitiendo escritura en texto plano.
		\item Soporte para múltiples formatos de salida: HTML, PDF (vía LaTeX), ePub, entre otros.
		\item Permite índices, referencias cruzadas, notas al pie, tablas y gráficos.
		\item Integración con sistemas de control de versiones (Git) y flujos CI/CD.
		\item Extensible mediante extensiones (plugins) para personalizar el estilo y funcionalidades.
		\item Ideal para documentación de proyectos de software y APIs.
	\end{itemize}

	\subsubsection*{Plataformas soportadas}
		\begin{itemize}
		\item Multiplataforma: Windows, Linux, macOS.
		\item Necesita Python instalado para funcionar.
	\end{itemize}

	\subsection {1. Swagger (OpenAPI)}
	Permite crear documentación interactiva de APIs REST, facilitando la comprensión y el consumo de los servicios web.\\
		URL sito oficial: 
	\href{https://swagger.io/}{Swagger}
	\begin{figure}[h!]
		\centering
		\includegraphics[width=0.3\textwidth]{swagger.jpeg}
		\caption{Logo Swagger} \cite{swagger_logo_assertible}
		\label{fig:Swagger} 
	\end{figure}
	\subsubsection{Características}
	\begin{itemize}
		\item \textbf{Portal web interactivo:} Genera automáticamente un portal web donde los usuarios pueden probar los \textit{endpoints} de la API, ver la estructura de las peticiones y respuestas, y ejecutar llamadas.
		\item \textbf{Compatibilidad:} Es compatible con múltiples lenguajes de programación y \textit{frameworks} como Java, Python, Node.js, y Ruby, entre otros.
		\item \textbf{Códigos HTTP:} Permite definir los códigos de respuesta HTTP (200, 201, 400, 500, etc.) para documentar los posibles resultados de cada operación.
		\item \textbf{Definición de esquemas:} Soporta la definición de parámetros de entrada y salida, modelos de datos y métodos de autenticación (como OAuth2 o API keys).
		\item \textbf{Estándar OpenAPI:} Está basada en la especificación OpenAPI, lo que garantiza que la documentación sea estandarizada y legible tanto por humanos como por m\'{a}quinas (formatos JSON o YAML).
	\end{itemize}

	\subsubsection{Ventajas y Limitaciones}
	
	\paragraph{Ventajas:}
	\begin{itemize}
		\item Documentación autom\'{a}tica y estandarizada.
		\item Interfaz interactiva que permite probar los \textit{endpoints} sin herramientas externas.
		\item Facilita la colaboraci\'{o}n entre desarrolladores y equipos de QA.
	\end{itemize}
	
	\paragraph{Limitaciones:}
	\begin{itemize}
		\item Requiere mantener actualizado el esquema OpenAPI para reflejar los cambios en la API.
		\item La interfaz puede ser limitada en personalizaci\'{o}n visual sin herramientas adicionales.
	\end{itemize}
